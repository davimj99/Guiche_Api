# 🎫 Guichê API

API REST desenvolvida em Java com Spring Boot para gerenciamento do sistema de guichês.

O projeto faz parte da evolução do sistema de guichê desenvolvido inicialmente em Django, com o objetivo de utilizar o Spring Boot como API/backend.

## 🚀 Tecnologias

- Java 26
- Spring Boot 4.1.0
- Spring Data JPA
- Hibernate
- PostgreSQL 18
- Maven
- Swagger / OpenAPI
